# Розподільчий логістичний комплекс (Тернопіль)

Безкоштовний односторінковий сайт-візитка на чистих HTML, CSS і JS — без збірки та залежностей.

## Як увімкнути GitHub Pages

1. Створіть репозиторій на GitHub і запуште код у гілку `main`.
2. Відкрийте **Settings → Pages**.
3. У розділі **Build and deployment → Source** оберіть **GitHub Actions**.
4. Після кожного пушу в `main` workflow `.github/workflows/pages.yml` автоматично опублікує сайт.
   Адреса: `https://<ваш-логін>.github.io/<назва-репозиторію>/`.

## Як змінити контент

- `index.html` — тексти, картки, цифри, контакти.
- `img/` — фото (стиснуті JPG).
- `style.css` — кольори в змінних `:root` (світла тема) і в блоці `prefers-color-scheme: dark` (темна).
- `script.js` — константа `RECIPIENT` (email, на який відкривається лист).

## Локальний перегляд

Відкрийте `index.html` у браузері.

## Примітка

Форма використовує `mailto:` — вона відкриває поштовий застосунок відвідувача, а не надсилає лист із сервера.
